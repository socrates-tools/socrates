**The rule half is decided over its whole input space**, beside the routing rule it agrees with, and not sampled.

**The reporting half asserts on what a command printed**, read back from the binary's output, and never on socrates' own source text.

**The skill half asserts on the rendered document**, never on the constants it is assembled from.

**Nothing here asserts that a page was made.** Publishing reaches the network, so what is driven is the fact socrates states and the instruction the skill carries. A test that claimed the page exists would read as passing while checking nothing.

**Each guard is mutated on purpose before it is trusted:** the test that proves the new behaviour is run against the old code first.

**`make lint test` after every task, not at the end of a group.**
