# Code of conduct

## What is expected

socrates is a project about reading each other's work honestly, so the standard here is the one the tool itself is built on: judge the change, not the person who wrote it.

- Say what is wrong with a change and why, and give the reason.
  A rejection with no reason is refused by the tool and it is refused here too.
- Assume the other person knows something you do not, and ask before concluding.
- Take a correction as information rather than as a loss.
- Keep it about the code, the specification and the decision.

## What is not

Harassment, insults, discriminatory language, sustained disruption, publishing somebody's private information, and unwelcome attention of any kind.
Dismissing a contributor rather than their argument.
Reopening a decision recorded in `docs/adr/` by attrition rather than by proposing a change to it.

## Reporting

There is no email address published for this project, deliberately: nothing here is worth publishing an inbox that only fills with spam.
Use GitHub instead, which is where everything else about the project already is.

- **Where a report can be public:** open an issue on this repository.
- **Where it cannot:** [open a draft security advisory](https://github.com/socrates-tools/socrates/security/advisories/new).
  It is private to you and the maintainer, and it is the one private channel this repository has.
  Say at the top that the report is about conduct rather than a vulnerability, and it will be read the same way.

Every report is read by the maintainer.
You will get an answer, you will be told what was decided, and what you sent is not repeated to the person it is about beyond what acting on it requires.

## What happens then

The maintainer may warn, ask for an edit or a retraction, close a thread, or block an account, in that order where the order makes sense.
There is one maintainer, so there is no appeal to a wider body; what there is instead is a public record of what was decided.

## Scope

This applies in this repository: issues, pull requests, discussions, commit messages and code review.
It applies to conduct elsewhere only where that conduct is directed at somebody because of this project.

## Attribution

Written for this project rather than adopted from a template, and deliberately short.
It is a commitment rather than decoration: a project that invites contribution and states no conduct has made the same commitment with none of the clarity.
