A workflow for delivering features with AI, from first idea to reviewed branch.

socrates takes your coding session through design, tickets, implementation and review. When it needs you, it opens a clear, interactive page in your browser instead of printing walls of markdown in the terminal.

WHY IT WAS BUILT

Humans and AI understanding each other before work starts

socrates exists so that people and AI reach a shared understanding before any work begins, rather than handing tasks over blindly. The socrates-design skill, for instance, settles every open question with you before a single line of the spec is written.

THE DECISIONS PAGE

Decisions on a page, not walls of markdown in a terminal

When a skill needs your input, socrates opens a page in your browser. Each question shows its options and what each one means, with the recommended choice marked. You click to answer, and your session picks it up from there.

INSTALL

What it needs

  • Claude CodeIt runs the skills. Codex support is coming.
  • For review, claude, codex or opencode on your PATHSigned in to an account. socrates is free, but every review is a model call billed to that account.
  • Linux or macOSOn Windows, use WSL.
  • git

From binary

curl -fsSL https://github.com/socrates-tools/socrates/releases/latest/download/install.sh | sh

This installs socrates and all four skills. It checks the download before installing anything, and running it again upgrades everything.

From source

git clone https://github.com/socrates-tools/socrates
cd socrates
make install

Does the same as the binary install. Needs Go 1.26 or later.

CONTRIBUTE

socrates is open source, and built the way it works

Every change here starts as a spec in docs/changes/<slug>/, with its tickets beside it. Run /socrates-design on your idea, or open an issue if you are not sure it needs one.

Architecture

One Go binary. Each namespace is a tool with its own directory.

design/The interview and the spec, and cutting it into tickets.
implement/Builds a change's tickets through implementers.
review/The independent reviewer.
agora/Serves the decisions page and waits for your answer.
internal/dispatcherRoutes socrates to each tool.

AGENTS.md maps the layout and invariants, CONTEXT-MAP.md the vocabulary, and docs/adr/ the decisions.

Run it locally

git clone https://github.com/socrates-tools/socrates
cd socrates
make install
make verify   # every gate, the same as CI

Needs Go 1.26 or later, git, and Chrome or Chromium for the page tests. Read CONTRIBUTING.md before opening a pull request.
