# Options sit two to a row on a wide window

This change makes the agora page lay out a decision's options two to a row on a wide window, as the design system's `OptionGroup` already does, instead of one long column.
It changes layout only: what a document states and what an answer carries stay the same.

Spec: [../spec.md](../spec.md). Decisions: none.
