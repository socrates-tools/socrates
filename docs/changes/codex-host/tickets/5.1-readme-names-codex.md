# 5.1: The README names Codex

## What to build

A person reading the README learns that Claude Code or Codex runs the skills, where an install puts each host's skills, what a Codex implementation needs from the sandbox, and that a review started from Codex reviews with `codex` unless `reviewer_cli` says otherwise.

## Acceptance criteria

- [ ] What socrates needs names Claude Code or Codex as what runs the skills.
- [ ] The install section says where each host's skills and implementer go, including `CLAUDE_CONFIG_DIR` and `CODEX_HOME`.
- [ ] The README names the writable root a Codex implementation needs and both ways to grant it.
- [ ] The review section says an unset `reviewer_cli` follows the host a review is started from.
- [ ] The README states only what is supported, and every documentation check in the suite passes.
