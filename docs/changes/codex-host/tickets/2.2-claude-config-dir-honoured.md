# 2.2: Claude Code's install follows CLAUDE_CONFIG_DIR

## What to build

A person whose Claude Code reads its configuration from `CLAUDE_CONFIG_DIR` gets every skill and the implementer's agent definition installed there, so `make install` and `socrates skill` install what their sessions load.
Where `CLAUDE_CONFIG_DIR` is unset, everything goes to `~/.claude` as today.

## Acceptance criteria

- [ ] With `CLAUDE_CONFIG_DIR` set, `socrates skill` writes every Claude Code skill under `$CLAUDE_CONFIG_DIR/skills` and the implementer's definition under `$CLAUDE_CONFIG_DIR/agents`, and writes nothing under `~/.claude`.
- [ ] With it unset, both go under `~/.claude` as today.
- [ ] Each install's announcement names the path it wrote.
- [ ] The record of where the definition was installed names the directory under `CLAUDE_CONFIG_DIR`, so `socrates implement configure` rewrites the definition Claude Code loads.
- [ ] The Claude Code renderings' Installing elsewhere sections say the skills go under `CLAUDE_CONFIG_DIR` where it is set.
