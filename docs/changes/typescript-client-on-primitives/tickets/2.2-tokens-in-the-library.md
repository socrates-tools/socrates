# 2.2: The tokens, fonts and mark live in the library

## What to build

The workspace gains its second package, `@agora/ui`, the library, and the tokens, the fonts and the mark move into it.
The surface package imports the library, and the library imports nothing from the surface.
The page and every illustration still load `/assets/tokens.css`, holding every custom property it holds today under the same name.
A colour or a font family written in any client stylesheet outside the library's tokens fails, as a colour written outside the palette fails today.

## Acceptance criteria

- [ ] The library is a workspace package of its own, and an import of the surface from inside the library fails the build.
- [ ] `/assets/tokens.css` is served with every custom property it held before this ticket, under the same names, and an illustration loading it is painted as before.
- [ ] A colour literal written in any client stylesheet outside the library's tokens fails the suite, naming the file.
- [ ] A font family named in any client stylesheet outside the library's tokens fails the suite, naming the file.
- [ ] `NOTICE` still accounts for every font the bundle embeds, and the browser suite passes unchanged.
