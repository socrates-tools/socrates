# 5.3: Code blocks and diff blocks are primitives

## What to build

The code block and the diff block move into the library as primitives, each with its partial, its contract entry and its states in the catalog.
Highlighting, splitting into numbered lines, and hanging a wrapped line further in than the line it continues belong to the code block.
The split diff's table and its own scroll belong to the diff block.
Evidence is rebuilt on them and keeps its own classes.

## Acceptance criteria

- [ ] Both are declared in the contract, drawn by one partial, and drawn in the catalog with a short line, a wrapped line, a tab-indented line, an unknown language and a patch.
- [ ] The browser suite proves line numbering, wrapping and highlighting against the catalog.
- [ ] Every browser test about evidence, highlighting and copying passes unchanged.
- [ ] The page's stylesheet no longer styles either itself.
