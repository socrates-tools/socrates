# 3.1: Drop and paste attach

## What to build

Dropping files on a decision or the composer attaches them to that tray.
Pressing Ctrl+V, or ⌘V on macOS, with the cursor anywhere in a decision or the composer attaches every file the clipboard holds, read from the paste event rather than the clipboard itself, so no permission prompt appears.
Text pastes as text as it does today, a clipboard holding both attaches the files and pastes the text, an unnamed pasted image is named `pasted-1.png`, `pasted-2.png` in the order it arrived, and the tray's ceiling and in-place refusal apply to a drop and a paste as to the button.

## Acceptance criteria

- [ ] Dropping two files on a decision attaches both to that decision's tray and to no other.
- [ ] Pasting an image with the cursor outside the words field of a card attaches it to that card's tray.
- [ ] Two pasted unnamed images arrive in the poll as `pasted-1.png` and `pasted-2.png`.
- [ ] Pasting text into the words leaves the text in the words and attaches nothing.
- [ ] Pasting a clipboard of files and text attaches the files and pastes the text.
- [ ] Pasting into a full tray refuses in place, naming the ceiling.
