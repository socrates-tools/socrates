# 3.4: A settled answer names its files

## What to build

A settled answer in a document carries `attached`, the names of the files collected for that identifier.
The folded settled block shows them, and the check of ADR 59 holds them as it holds the question, the labels and the words: a revision that drops, adds or renames one is refused before it is written or served.

## Acceptance criteria

- [ ] A revision settling a collected answer with the attachment names exactly as collected is served, and the settled block shows the names.
- [ ] A revision dropping, adding or renaming one is refused naming the identifier.
- [ ] A revision settling an answer collected with no attachments and stating none is served as today.
