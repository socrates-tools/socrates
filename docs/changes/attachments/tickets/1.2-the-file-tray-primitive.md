# 1.2: The file tray primitive

## What to build

A new primitive, `ui-file-tray`, naming nothing of agora's domain: an attach button opening the file picker, a drop target, a chip per file with a thumbnail for an image and a type badge for anything else and a control removing it, a counter of how many it holds against its ceiling, and an in-place refusal naming the ceiling when more are added than it takes.
It is reached through `files`, `add(files)` returning the files it refused, and `clear()`, and announces `change` and `refused`.
It slots its label, its hint and its refusal, declares its ceiling as an attribute, previews from a `blob:` URL, and is drawn in the catalog in every state it has.
It is not on the page yet.

## Acceptance criteria

- [ ] The catalog draws the tray empty, holding an image and a non-image, full at its ceiling, and refusing.
- [ ] Attaching an image shows its thumbnail, and attaching a text file shows a type badge.
- [ ] Removing a chip removes that file from `files` and announces `change`.
- [ ] Adding an eleventh file to a tray of ten leaves it holding ten, announces `refused`, and shows the refusal naming the ceiling where it was added.
- [ ] The contract test holds the tray's attributes and slots as it holds every primitive's.
