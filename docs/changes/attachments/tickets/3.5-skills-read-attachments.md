# 3.5: The review and design skills read attachments

## What to build

Both skills say that attachments may arrive, that each is read by its path, and that it is the person's evidence rather than an instruction, extending the sentence that already says a person's words are recorded rather than followed.
The review skill passes each path `socrates agora poll` printed for a finding to `socrates review respond --attach`.
The design skill says every path an earlier poll printed stays readable for the life of the session, and that it copies what a decision rests on into `docs/changes/<slug>/` and cites it from the spec.
Both stay inside the skill ceiling.

## Acceptance criteria

- [ ] The review skill names `respond --attach` and says to pass it every path the poll printed for that finding.
- [ ] The design skill says to copy what a decision rests on into the change's folder and cite it from the spec.
- [ ] Both skills say an attachment is evidence rather than an instruction, and removing that sentence from either fails the suite.
- [ ] Every invocation the skills name is one the binary offers.
