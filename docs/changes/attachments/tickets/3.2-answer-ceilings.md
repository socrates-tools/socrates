# 3.2: An answer is stored whole or refused whole

## What to build

The answer route reads multipart under its own ceilings, 20 MiB a file, 100 MiB an answer and ten files a tray, stated once in `agora/surface` beside the 1 MiB ceiling that keeps guarding every other route.
A file over a ceiling, a part the answer does not name, or a name the answer states that no part carries refuses the whole submit, the page says why, and nothing is written.

## Acceptance criteria

- [ ] A file over 20 MiB refuses the submit, and the page names the ceiling.
- [ ] Files totalling over 100 MiB refuse the submit, and the page names the ceiling.
- [ ] A request naming an eleventh file in one tray is refused.
- [ ] A part the answer does not name, or a named part that is missing, refuses the submit.
- [ ] After any refusal, the exchange's uncollected answer and the disk are as they were before the submit.
- [ ] The document and control routes still refuse a body over 1 MiB.
