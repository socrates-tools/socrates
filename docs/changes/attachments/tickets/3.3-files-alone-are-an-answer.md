# 3.3: Files alone are an answer, and what goes names them

## What to build

The rule that decides what is sent counts a decision holding files as answered, so the index ticks it and the confirmation never names it as blank.
The reply panel's summary and the receipt name the files beside the words, for each decision and for the message.

## Acceptance criteria

- [ ] A decision holding only a file is ticked in the index and counted.
- [ ] A press with a decision holding only a file raises no confirmation naming it.
- [ ] That decision appears in what `socrates agora poll` prints with its attachment and no words.
- [ ] The summary names each attached file under its decision and under the message before a press.
- [ ] The receipt names each file that went.
