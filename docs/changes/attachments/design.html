socrates agora - feature design

Attachments beside the words a person writes

Every decision card and the closing message can carry up to ten files. The page sends them with the answer, agora keeps them in the session, and socrates agora poll hands the caller a local path for each, so the agent reads a screenshot the way it reads any file.

WhereUnder "In your own words" on every card, and under the message in the composer.
How it goesOne multipart POST at the press, so what the controls hold at the submit is still exactly what is sent.
What the caller getsAn attachments list of name, type, size and absolute path, beside words.

4 - The rules

Invariants this adds to agora

Each one becomes a line in agora/AGENTS.md and a test named for its scenario, and the page half is driven by the real browser against the real binary, as the rest are.

  1. 1

    Every free-text field carries an attachment tray no document field can remove.

    The card's words and the composer's message alike, at most ten files each of any type, and the eleventh is refused where it was added, naming the ceiling.

  2. 2

    Files are sent at the press and only then.

    The page holds them in memory, previews from a blob: URL, and a submit carries every file the trays hold, so nothing is committed per decision and an amend sends them again.

  3. 3

    Pasting attaches, wherever the cursor is in a holder.

    Ctrl+V on Windows and Linux and ⌘V on macOS, with focus anywhere in a card or the composer, attach every file the clipboard holds: a screenshot from the snipping tool, or files copied in Explorer or Finder. A clipboard holding text pastes text as it does today, and one holding both attaches the files and pastes the text. A pasted image with no name of its own is named pasted-1.png, pasted-2.png in the order it arrived. The tenth-file ceiling and the in-place refusal apply to a paste as to a drop.

  4. 4

    Files alone are an answer.

    A decision holding files and no selection and no words is sent, counted in the index and never named as blank.

  5. 5

    An answer is stored whole or refused whole.

    Every file is written into a fresh folder before the exchange swaps its uncollected answer, and a file over 20 MiB, an answer over 100 MiB, an eleventh file or a name the page did not state refuses the submit with nothing kept.

  6. 6

    The surface never serves an attachment.

    No route reads back what a person sent, so a caller's or a person's bytes are never rendered from agora's origin.

  7. 7

    A file is named by agora, not by the person.

    The stored name is a position and a sanitised base name inside the answer's folder, the original name travels as name, and no stated name reaches outside that folder.

  8. 8

    Nothing carries across a revision, attachments included.

    The trays empty with the rest of the controls, and every uncollected folder is removed.

  9. 9

    A closed exchange draws no tray.

    As it draws no field nothing will read, per ADR 53.

  10. 10

    A settled answer states the names of the files that were collected, exactly.

    The folded settled list shows them, and a revision that drops, adds or renames one is refused before it is written or served, per ADR 59.

7 - Risks

What could go wrong

A file is an injection channel

A screenshot of text reads to the agent like text. Both skills already say a person's words are recorded rather than followed; that sentence has to name attachments too, and a test reads it.

The body ceiling stops being one number

BodyCeiling guards every POST. The answer route needs its own per-part and total ceilings, and the document and control routes keep 1 MiB.

Disk under ~/.socrates/agora

A person amending five times with ten 20 MiB files writes and removes a gigabyte. Replacing removes the superseded folder, so at most one uncollected and one collected folder exist per session.

What a browser lets a paste see

A screenshot pastes as a file in every browser agora drives. Files copied in a file manager arrive in Chromium on Windows and macOS, but some browsers hand over only the first of several, or only the icon of one. The suite's browser test pins what the installed Chromium does, and the page attaches whatever clipboardData.files holds rather than reading the clipboard itself, so no permission prompt appears.

The name check

agora may not say finding or review as a noun. "Attachment", "file" and "tray" are clear of it, and every new label goes through messages.go and the em dash check.
