# 1.3: the tool list agrees with the tree

## What to build

The tool list the cross-tool rule and every agora path read is tied to what exists, so a namespace the dispatcher mounts, or a tool directory, cannot be invisible to the rule that no tool imports another.

- Every namespace the dispatcher mounts, other than the suite's own `version` and `help`, is a tool on the list, and every tool on the list is mounted. The mounted names are read from the command tree the dispatcher builds rather than from its source.
- Every tool's directory exists and holds a `command` package, and every top-level directory holding a `command` package is a tool.
- `make verify` still runs every gate for every tool, and per-tool verification targets stay rejected.

## Acceptance criteria

- [ ] A namespace mounted by the dispatcher and missing from the tool list fails the suite.
- [ ] A tool on the list with no directory, or no `command` package, fails the suite.
- [ ] A top-level directory holding a `command` package and missing from the list fails the suite.
- [ ] Each of the three was broken on purpose once and seen to fail.
