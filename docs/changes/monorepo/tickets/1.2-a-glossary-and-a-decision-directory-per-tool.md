# 1.2: a glossary and a decision directory per tool

## What to build

The documentation splits by tool, the way the source already does.
`CONTEXT.md` is one file sectioned per tool, `docs/adr/` is one directory, and `AGENTS.md` is one long file whose invariants are several lists stapled together.

- `CONTEXT-MAP.md` at the root points at each tool's glossary, and the domain docs say the layout is multi-context.
- A glossary per tool, with the shared terms of the suite at the root. agora's glossary holds none of review's words, because agora's defining invariant is that it does not know what a review is.
- Decision records per tool, beside the root's records about the suite: the page and the loopback window go to agora, a design to design, the one binary, the command surface and one configuration file per tool stay at the root, and the rest go to review.
- Records keep their numbers when they move: one number space across the root and every tool's directory, gaps and all, so a number names one document wherever it sits and every cross-reference and commit message still resolves. New records continue from the highest number.
- The instruction file splits the same way: the root keeps the map, the verification sequence and the suite's invariants, and each tool takes its own layout and invariants. Stale lines and restated rationale go rather than move.
- ADR 13 is marked superseded by a record that the suite is one module rather than one per tool, stating that an independent release cadence was the goal of the rejected first draft and is given up deliberately.

## Acceptance criteria

- [ ] Every tool has a glossary of its own, and the root's map names each one.
- [ ] Every decision record sits with the tool it is about, or at the root where it is about the suite, under the number it already had.
- [ ] Every relative link and every ADR cross-reference resolves after the move.
- [ ] ADR 13 is superseded, and the record superseding it says what is given up.
- [ ] The checks that the documents a first change needs are present and agree with each other hold over the new layout.
