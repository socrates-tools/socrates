# 2.1: The second round reads a settled answer as the session's decision

## What to build

A fresh reviewer judging the second round of a run with nobody to ask is told that a settled response is the decision of the session that started the run, with its reason, and judges it as a claim, the way it judges a person's decision today.
A decided response is still named as a person's answer, so the reviewer can tell the two apart.

## Acceptance criteria

- [ ] The prompt delivered to the second round's reviewer, for a finding answered with `--settled`, says the session that started the run decided it and gives the reason; today such a response is not described as a decision at all.
- [ ] That prompt never says a person answered a settled finding.
- [ ] For a finding answered with `--decided` on a run without `--nobody-to-ask`, the delivered prompt still says a person answered it.
- [ ] The prompt asks the reviewer to judge whether the code matches what was settled, and to say so where the settlement leaves the finding unresolved.
