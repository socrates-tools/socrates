# 1.4: The browser suite holds what the Go page tests hold

## What to build

Each behaviour the Go tests that read the page's rendered HTML hold, and the browser suite does not already, is held by the browser suite against the real binary.
That covers at least the index's order by severity, every mark's word and hover text, what was settled and when it arrives folded, the pieces and the classes the script finds them by, the diff heading's file names and counts, a patch with no hunk left out, the line under the title, and a recommended option arriving chosen.
The Go tests stay until the page they read is gone.

## Acceptance criteria

- [ ] Breaking any one of those behaviours on purpose in the page as Go draws it today makes a browser test fail, naming the behaviour.
- [ ] No behaviour a Go test of the rendered page holds is held by no browser test.
