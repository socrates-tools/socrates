# 1.2: The wording check holds the client's messages

## What to build

The page's client gains one messages module, and the wording check reads its plain string literals as it reads every Go messages file: no em dash, and each names what the person can do.
The check that no word names review's nouns reads it too, with the three audiences socrates review writes exempted by name there as they are in Go today.
No word moves yet.

## Acceptance criteria

- [ ] An em dash in a string of the client's messages module fails the suite, naming the module and the line.
- [ ] A string there that names nothing a person can do fails the suite as it would in a Go messages file.
- [ ] A string there naming review, finding, verdict, round or run as a noun fails the suite, and the three audiences named by the exemption do not.
- [ ] Removing the client's messages module fails the suite rather than passing it.
