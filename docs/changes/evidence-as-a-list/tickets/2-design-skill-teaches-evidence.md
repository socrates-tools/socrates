# 2: The design skill shows code through evidence

## What to build

socrates-design teaches evidence for code on a card.
It says that code goes in evidence, as data, and that an illustration never draws code on its own: an illustration may still show code as part of a drawn screen or layout, but a card that only shows code uses evidence.
It shows a card comparing two shapes as two captioned blocks, one per option, written in `tsx`, and says a before and after is a patch block.

## Acceptance criteria

- [ ] The installed socrates-design skill says code on a card goes in evidence.
- [ ] It says an illustration never draws code on its own, and that one may still show code inside a drawn screen or layout.
- [ ] Its example of a card comparing two shapes, served as written, shows two captioned, highlighted `tsx` blocks.
- [ ] It says a before and after is shown as a patch block.
