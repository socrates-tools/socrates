# 1.4: A language may be named by any name highlight.js answers to

## What to build

A document may name a block's language by any name highlight.js answers to: the common set and every alias its languages register, such as `tsx`, `jsx`, `ts`, `sh` and `yml`.
Code named by an alias is highlighted as its language is.
A name highlight.js does not know is still refused, and the refusal lists the accepted names.
The accepted names stay generated from the client's source, and agora's languages invariant says they are the common set and its aliases.

## Acceptance criteria

- [ ] A document naming `tsx` is served rather than refused, and its JSX is highlighted on the page.
- [ ] A document naming `jsx`, `ts`, `sh` or `yml` is served, and its code is highlighted.
- [ ] A patch whose language is named by an alias has its lines highlighted.
- [ ] The refusal for a language highlight.js does not know lists the aliases among the accepted names.
