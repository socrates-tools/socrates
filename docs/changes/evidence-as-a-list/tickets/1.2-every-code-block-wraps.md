# 1.2: Every code block wraps its long lines

## What to build

Every line of a code block wraps at the width of its card, whatever its language, with continuation lines indented so a wrapped source line still reads as one line.
Nothing in a code block scrolls sideways.
The split diff of a patch keeps its table and is not part of this ticket.

agora's invariant that only markdown wraps becomes one that every code block wraps with its continuation lines indented.

## Acceptance criteria

- [ ] A line of Go wider than its card wraps onto further lines rather than scrolling sideways.
- [ ] The continuation of a wrapped line starts further in than the line it continues.
- [ ] No code block on the page can be scrolled sideways, at a narrow window and at a wide one.
- [ ] Markdown evidence still wraps at the width of its card.
