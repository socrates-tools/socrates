# 1.3: Copy a code block

## What to build

Every code block on a card offers a copy control.
Pressing it puts the block's code, exactly as the document stated it, on the person's clipboard, and sends nothing anywhere.
The control says what it does on hover, on focus and to a screen reader, and confirms the copy where it was pressed.
A patch's split diff offers no copy control.

## Acceptance criteria

- [ ] Every code block on the page shows a copy control, and a patch's split diff shows none.
- [ ] Pressing the control puts the block's code on the clipboard, byte for byte as the document stated it, including its indentation and line breaks.
- [ ] The control can be reached by keyboard and is named to a screen reader.
- [ ] Pressing it changes nothing about the answer the page would send.
