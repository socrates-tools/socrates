# 1.1: Evidence is a list of captioned blocks

## What to build

A decision's evidence is a list of blocks, per ADR 78.
Each block holds either code in a language or a patch, and may carry a caption.
The page draws one block after another, in the order the document listed them.
A block's heading shows its caption where there is one, with the language or the patch's file beside it, and the language or file alone where there is none, as today.

The list is the only shape read.
A document whose evidence is an object is refused before anything is served, naming the decision, saying evidence is a list of blocks, and saying to install the skill again.
A block holding both code and a patch is refused, naming the decision, and so is a block holding neither.

review's skills and socrates-tickets write a list where they wrote an object, and a finding showing code and a patch passes two blocks.
The committed skills are regenerated, and everything in the repository that writes evidence moves to the list.

## Acceptance criteria

- [ ] A decision whose evidence lists two code blocks shows both on its card, in the order written.
- [ ] A block with a caption shows that caption in its heading, with its language beside it.
- [ ] A patch block with a caption shows the caption in its heading, with the patch's file beside it.
- [ ] A block with no caption shows its language, or its patch's file, alone, as it does today.
- [ ] `socrates agora serve` given a document whose evidence is an object refuses it before printing an address, and the refusal names the decision, says evidence is a list of blocks, and says to install the skill again.
- [ ] A block holding both code and a patch is refused before anything is served, naming the decision.
- [ ] A block holding neither code nor a patch is refused before anything is served, naming the decision.
- [ ] The installed socrates-review, socrates-review-handover and socrates-tickets skills show evidence as a list, and socrates-review says a finding showing code and a patch passes two blocks.
- [ ] A ticket round served from what socrates-tickets teaches shows each ticket's file as it did before.
