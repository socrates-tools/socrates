# 1.2: every socrates skill is invoked by a person only

## What to build

Every skill the binary ships can be started by a person only, per ADR 49, so no skill reaches for another.
`socrates-review`, `socrates-review-handover`, `socrates-design` and `socrates-tickets` carry `disable-model-invocation: true` in their front matter, stated once in the machinery every namespace renders its skills through.
A design's last card stops offering to cut the tickets next: it offers write it, and nothing else.
`socrates-tickets` stops naming a design that handed on to it, and mints its own session.

## Acceptance criteria

- [ ] Every installed and committed socrates skill carries `disable-model-invocation: true`.
- [ ] A skill some namespace ships without it fails the suite, checked over every namespace rather than a list, and that check was broken on purpose once.
- [ ] A design's last card offers write it and nothing that starts another skill.
- [ ] `socrates-tickets` says nothing about a design handing on to it.
- [ ] The map's invariants for the design skill and the tickets skill say the same.
