# 2.2: the implementer's agent definition is installed

## What to build

`socrates implement skill` writes the implementer's agent definition, `socrates-implementer.md`, into Claude Code's agents directory, `~/.claude/agents` by default, or into the directory `--agents-to` names, per ADR 50.
Its front matter carries the model and effort in force and runs the implementer in the background.
Its body is the implementer's standing instructions: work in the worktree you were briefed with and nowhere else; follow the repository's own instructions, including how it tests; commit on your own branch; run the repository's own verification before reporting; merge the change's branch into your own before reporting done; report what you did and what you did not; patch your own work when feedback arrives; never invoke a socrates skill.
The command records where it wrote the definition in a file of its own under socrates implement's directory, never in the configuration file.
`make install` installs it, and `make skill` regenerates its committed copy.

## Acceptance criteria

- [ ] The definition is written under the default directory, and under `--agents-to` where one is named.
- [ ] Its model and effort are the settings in force, at the defaults and after a person set each.
- [ ] Where it was written is recorded, and a second install somewhere else replaces the record.
- [ ] The committed copy matches what is rendered at the defaults.
- [ ] The definition names no `socrates` command, and that check was broken on purpose once.
- [ ] The definition is held to a ceiling of its own.
