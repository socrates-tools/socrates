# 1.1: the configure menu is shared machinery

## What to build

The menu `socrates review configure` draws becomes machinery a second menu can be built on, so socrates implement's menu and review's cannot drift.
What moves: the menu itself, the YAML document that keeps a person's comments, key order and blank lines through a write, the atomic write, and the reading of a line the loader could not read.
Review's own settings, labels and refusals stay review's.
A person running `socrates review configure` notices nothing.

## Acceptance criteria

- [ ] `socrates review configure` draws, writes, resets a setting with *use the default*, repairs an unreadable line and refuses where nothing is a terminal exactly as before.
- [ ] Review's existing end-to-end tests of the menu pass unchanged.
- [ ] Nothing of the shared machinery names review, a review setting or a review file.
