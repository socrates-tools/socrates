# 2.1: the default branch is remembered per repository

## What to build

socrates remembers the branch a repository's features start from, per ADR 51, so the overseer asks for it once.
`socrates implement default-branch <branch>` saves it for the repository it runs in, under `default_branches` in socrates implement's own file, keyed by the top level of the repository's main worktree, and leaves every other line of the file alone.
`socrates implement config`, run inside a repository, also reports that repository's `default_branch`, and prints it empty where nothing is remembered rather than guessing one.

## Acceptance criteria

- [ ] Saving a branch the repository holds writes the entry for that repository, and `config` run there reports it as set.
- [ ] A branch the repository does not hold is refused, and the file is untouched.
- [ ] A worktree of the clone reads the same entry as the clone.
- [ ] A second clone of the same repository at another path reports nothing remembered.
- [ ] Run outside a repository, `default-branch` is refused naming what it needs, and `config` reports no `default_branch`.
- [ ] A person's comments, key order and blank lines in the file survive a save.
