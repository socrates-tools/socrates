# 1.3: socrates implement exists and reports its settings

## What to build

`socrates implement` is a fourth namespace, per ADR 48, mounted by the dispatcher and registered as a tool so the rule that no tool imports another covers it.
It has a directory of its own under the brand's root, and `SOCRATES_HOME` moves it with the rest.
`socrates implement config` names `~/.socrates/implement/config.yaml` and reports every setting by its YAML key, with the value in force and whether a person set it, in the shape `socrates review config` reports:

- `concurrency`, a positive whole number, default 4.
- `roles.implementer.model`, a Claude Code model alias or a full model identifier, default `sonnet`.
- `roles.implementer.effort`, one of `low`, `medium`, `high`, `xhigh` and `max`, default `high`.

Each default is stated once, beside the settings, and what `config` reports is read from there.

## Acceptance criteria

- [ ] `socrates implement config` with no file reports the three settings at their defaults, each as a default.
- [ ] A setting a person wrote is reported with its value and as set.
- [ ] A value out of range, and a field the file does not have, are refused naming the file.
- [ ] `socrates --help` lists `implement`, and `socrates implement --help` lists what it holds.
- [ ] A reported default and the default its owner states agree.
- [ ] The map names the fourth namespace, its packages and its file beside review's and agora's.
