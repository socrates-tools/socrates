# 2.8: The landing page styled with utilities

## What to build

A contributor styles the landing page with the same utilities as the page, against the same theme, and `make assets` writes its stylesheet as a committed generated file that `make site` copies, so `make site` and a release need no Node.
The landing page looks as it does today.

## Acceptance criteria

- [ ] The landing page looks as it did before, at every width the landing page suite drives.
- [ ] `make site` builds the site without Node or `pnpm` installed.
- [ ] Changing the landing page's markup or its Tailwind entry without running `make assets` fails `make verify`, because the stamp no longer matches.
- [ ] The landing page's generated stylesheet carries Tailwind's notice, and `NOTICE` says it does.
