# 2.7: The glossary's pieces and the catalog laid out by utilities

## What to build

A contributor lays out a piece the glossary names, such as a decision, the composer, the receipt or the index, with utilities in the Go markup that draws it, and the catalog's own layout is written the same way.
The surface's stylesheet and the catalog's keep only what utilities cannot say, each piece keeps the one class that names it for the script and the suite, and the check that held the surface's stylesheet to the glossary's pieces is retired.
The page looks as it does today.

## Acceptance criteria

- [ ] The page at 480px, 960px and 1280px, with nothing answered, partly answered, sent, and closed, looks as it did before.
- [ ] Every text still meets the contrast floor, and an element the page hides paints nothing.
- [ ] The surface's stylesheet holds no rule a utility could say, and the catalog's likewise.
- [ ] Nothing in the suite reads `convention.PiecesOfTheSurface`, and no check fails because a piece's class is not listed.
