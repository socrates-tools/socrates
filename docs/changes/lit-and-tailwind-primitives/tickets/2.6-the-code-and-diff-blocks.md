# 2.6: The code block and the diff block as Lit elements

## What to build

The code block and the diff block are Lit elements rendering into shadow roots, highlighting with the tokens' syntax colours, and every piece of evidence reads as it does today.
A code block still wraps at its card's width, hangs a continuation line further in than its source line, numbers its lines from 1 in a gutter that is not part of its text, and is painted the white of its card, and a patch's split diff is still a table with its own scroll.

## Acceptance criteria

- [ ] Both have a shadow root on the page and in the catalog, and every state the catalog draws of each looks as it did before.
- [ ] Highlighting, wrapping, hanging indentation and numbering behave as they did, in every language the page highlights.
- [ ] Selecting and copying a code block's text by hand copies no line number.
- [ ] Each one's partial writes only the element, its declared attributes and its slotted content, held by the Go contract test.
