# 1.1: The foundation, proved on the badge

## What to build

A contributor can write a primitive as a Lit element styled with Tailwind utilities that paint only the tokens, and the badge is the first one built that way, end to end.
`make assets` compiles one Tailwind stylesheet whose own theme is cleared and whose utilities are the tokens in `tokens.css`, with one spacing step added, Preflight included, and the classes read from the client's TypeScript, the partials and the landing page.
That stylesheet is adopted by every Lit primitive's shadow root as one shared sheet and is also loaded on the document.
The contract `make assets` writes declares, for each Lit element, the attributes it reads and the slots it renders, beside the parts the primitives not yet moved still declare, and the Go contract test holds a partial of each kind to what its element declares.
The badge renders into a shadow root, its partial writes only the element, its attributes and its slotted label, and it looks and behaves on the page and in the catalog as it does today.
Lit and Tailwind are named in `NOTICE`, and the shipped bundle carries each one's notice in the file its code ships in.
The surface's TypeScript cannot reach into a shadow root.

## Acceptance criteria

- [ ] `<ui-badge>` on the page and in the catalog has a shadow root, and every badge state the catalog draws looks as it did before.
- [ ] The badge's mark still says what it means on hover, on focus and to a screen reader, on a card and in the index.
- [ ] The browser suite records no Content-Security-Policy violation on the page or the catalog, with the shared sheet adopted, and the page's policy is unchanged.
- [ ] A partial writing an attribute or a slot the badge does not declare fails the Go contract test naming the badge and the attribute or slot, and so does a declared attribute or slot no partial writes.
- [ ] A primitive not yet moved is still held to its parts by the same test.
- [ ] `bg-red-500` or `rounded-lg` written in a template produces no rule in the built stylesheet, while `bg-accent`, `rounded-pill`, `font-body` and `p-4` do, `p-4` being 16px.
- [ ] `/assets/tokens.css` states every custom property it stated before, and `--spacing` beside them.
- [ ] Primitives not yet defined paint nothing until the bundle defines them.
- [ ] `NOTICE` names Lit and Tailwind CSS with their full licence texts, and the suite fails where Lit's notice is missing from `surface.js` or Tailwind's from `surface.css`.
- [ ] A file of the surface's TypeScript naming `shadowRoot` stops `make assets`, naming the file and the line, and `scripts/prove-client-build` proves it.
- [ ] `make verify` passes and still needs no Node.
