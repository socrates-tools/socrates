# 2.5: The app shell as a Lit element

## What to build

The app shell is a Lit element rendering into a shadow root, slotting the topbar, the navigation, the content and the panel Go writes, and the page fills the window as it does today.
From 960px only the navigation and the content scroll and the navigation marks the section in view, from 1280px the reply panel holds the composer, and below 960px everything stacks and scrolls with the window.

## Acceptance criteria

- [ ] The app shell has a shadow root on the page and in the catalog, and the catalog's 480px, 960px and 1280px frames look as they did before.
- [ ] At each width the shell scrolls, stacks and marks the section in view as it did.
- [ ] The composer moves between the panel and the end of the decisions as the window crosses 1280px, keeping what was typed.
- [ ] Its partial writes only the element, its declared attributes and the slots it fills, held by the Go contract test.
