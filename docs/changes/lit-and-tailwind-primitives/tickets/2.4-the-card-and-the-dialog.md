# 2.4: The card and the dialog as Lit elements that slot what they wrap

## What to build

The card and the dialog are Lit elements rendering into shadow roots and composing what Go writes inside them by slots, so a decision, the composer, the empty page and the confirmation are drawn on them as they are today.
The confirmation still names every blank decision, dims what is behind it, sends from a press inside it, closes from each name onto that card's first control, and returns the cursor to the button that raised it on going back, Escape or a press on the backdrop.

## Acceptance criteria

- [ ] The card and the dialog each have a shadow root on the page and in the catalog, and every state the catalog draws of each looks as it did before.
- [ ] A press over a blank decision raises the confirmation naming each one, and each of its paths behaves as it did.
- [ ] A revision that replaces the surface while the confirmation is open leaves nothing of it listening.
- [ ] Each one's partial writes only the element, its declared attributes and the slots it fills, held by the Go contract test.
