# 1.2: No class string carries an arbitrary value

## What to build

A contributor who writes a Tailwind utility with an arbitrary value, such as `p-[13px]` or `bg-[#fff]`, in the client's TypeScript, a partial or the landing page is stopped by the suite, which names the file and the line.
The paths the check reads are the paths Tailwind reads classes from, stated once.

## Acceptance criteria

- [ ] A utility with an arbitrary value in a file of the client's TypeScript fails `make verify`, naming the file and the line.
- [ ] The same holds for one in a partial and for one in the landing page's `index.html`.
- [ ] A square bracket that is not part of a class string, such as an attribute selector in TypeScript or an index into an array, fails nothing.
- [ ] The check proved over a scratch tree holding each violation fails on every one, so the check is known to work.
