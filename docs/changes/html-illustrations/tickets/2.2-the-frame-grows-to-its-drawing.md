# 2.2: The frame grows to its drawing

## What to build

The surface adds one script of its own to the end of each copied HTML document's body, which posts the document's height to the page whenever it changes.
The page sets that card's frame to the height, capped at the window's height, and a taller drawing scrolls inside its frame.
The page accepts only a finite non-negative number from that card's own frame and ignores every other message, so a drawing still cannot write into an answer.

## Acceptance criteria

- [ ] A short drawing's frame is the drawing's height, with no gap under it.
- [ ] A drawing taller than the window stops at the window's height and scrolls inside its frame.
- [ ] A drawing that grows after loading, such as by a script adding rows, grows its frame.
- [ ] A frame posting anything but a number, or posting for another card, changes nothing on the page.
- [ ] The drawing's own markup and script are otherwise served exactly as written.
