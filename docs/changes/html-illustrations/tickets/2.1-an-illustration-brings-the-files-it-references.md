# 2.1: An illustration brings the files it references

## What to build

When an illustration is served, the files its HTML references come with it: every relative `src`, `href` and `srcset` in the HTML, and every relative `url(...)` and `@import` in any CSS it reaches.
They are copied into the session beside the HTML file and served from the illustration's route with their stated media type.
An absolute reference, one naming a scheme, and a fragment alone are left as they are.
An illustration's files total at most 16 MiB, and each is HTML, CSS, JavaScript, JSON, SVG, PNG, JPEG, WebP, GIF, WOFF or WOFF2.
A reference leaving the HTML file's folder, a missing file, a file of another type, or a total over the cap is refused before the document is written or served, naming the decision and the file.

## Acceptance criteria

- [ ] A drawing showing two PNG screenshots side by side, referenced relatively, renders both on its card.
- [ ] A stylesheet the HTML links, its `url(...)` background and its `@import` are all copied and applied.
- [ ] A reference such as `../secret.png` is refused, naming the decision and the reference, and nothing is served.
- [ ] A referenced file that is missing, or of a type outside the list, is refused, naming it.
- [ ] An illustration whose files total over 16 MiB is refused, naming the decision.
- [ ] A reference to a CDN URL is not copied and still loads where ADR 77 admits it.
