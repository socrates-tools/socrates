# 2.3: A drawing expands to fill the window

## What to build

Each illustration's card offers an expand control that lays the drawing over the whole window, with the page dimmed behind it.
A close button, Escape and a press on the backdrop each close it, and the cursor returns to the expand control.
The frame is laid over the page by style rather than moved in the document, so the drawing keeps whatever state its script built.
The control and its frame follow the design system, whose illustration component is redrawn as the frame with its expand control, and its labels live with the page's other words.

## Acceptance criteria

- [ ] Pressing the expand control shows the drawing filling the window at every width the page supports, including below 960px.
- [ ] Escape, the close button and a press on the backdrop each return to the card with the cursor on the expand control.
- [ ] A drawing whose script changed its state before expanding shows the same state expanded and after closing.
- [ ] The control says what it does on hover, on focus and to a screen reader.
