# 2.4: A drawing may link the page's tokens

## What to build

The surface serves the page's colour tokens, type scale and fonts as one stylesheet among its embedded assets, at an address the skills can name.
A sandboxed frame fetches it from an opaque origin, so it and its fonts are served with `Access-Control-Allow-Origin: *`, and the frame's policy admits the surface's own origin by name.
A drawing that links it reads as part of the page around it.

## Acceptance criteria

- [ ] A drawing that links the tokens stylesheet is painted with the page's own fonts and colours.
- [ ] The tokens in that stylesheet are the ones the page paints with, so a token changed in the design system changes both.
- [ ] A drawing that does not link it is painted only by its own styles.
